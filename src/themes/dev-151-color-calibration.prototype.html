Should an exact brand color occupy a numbered shade, or stay intact beside a balanced scale? Compare the same input under both policies, then inspect a limited palette and light/dark interface. This experiment calibrates color behavior; it is not the production workshop.

Walk through the awkward cases

The UI illustrations use a simple semantic policy: action fills contrast with their panel as well as their label. An exact bright brand can alternatively work with a contrasting outline; a darker related fill is not the only accessible option. Production role mapping belongs to DEV-154.

Candidate default: preserve the source, calibrate the scale.

Keep the original brand color as an exact reference. Use a regular, brand-related ramp for the wall, and select semantic colors for their actual use. Label the closest shade as an approximation. Offer an explicit “pin exact color into the wall” option.

This is a recommendation for visual review, not an approved production contract. sRGB is the calibration target. Display P3 enhancement and its separately checked fallback belong to the next implementation study; this page does not simulate a P3 display.
