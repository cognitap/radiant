## Built for actions

Use Button to submit a form, confirm a choice, or change something on the page.
It renders a native button and defaults to `type="button"`. Use Link when the
action takes someone to another page.

```tsx
import { Button } from '@cognitap/radiant'
import '@cognitap/radiant/styles.css'

export function ContinueButton({ onContinue }: { onContinue: () => void }) {
  return <Button onClick={onContinue}>Continue</Button>
}
```
